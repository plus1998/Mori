# JEV Agent 审批实测

使用 Eco 开发配置中启用的 JEV Provider，实际请求返回模型版本为 `jev-1.13.0`。评测通过项目的 `reviewEcoApproval` 和 System One HTTP 请求运行；拟审批动作不执行，只有测试脚本自己的临时 fixture 被创建和清理。Provider 配置以只读方式加载，未输出或保存密钥。

最终验证：30 个场景，每个重复 3 次，90/90 符合预先设定的期望。57 次自动允许，21 次转人工，12 次拒绝。90 次均获得有效模型响应。审批耗时中位数 384 ms，P95 为 480 ms，包含模型请求与放行前宿主复核。

## 实测中发现的缺口及修正

初测 15 项中有 2 项 memory 没有被接管：模型选择允许，但决策置信度分别为 86% 和 89%，低于宿主的 90% 门槛。将 decision 的三个选项描述细化为明确的自动允许范围、具体人工条件和绝对拒绝条件后，同一组 15 项全部通过；最终 30 场景三轮验证中，普通 memory 全部允许。90% 放行置信度与风险/授权概率门槛保持不变。

第一次扩展的 90 请求中，1 次组织人工审批场景返回了未通过概率契约校验的响应，宿主转人工，评测计为失败。该次未捕获原始答案，因此不能确定具体无效字段；失败记录保留。随后补充原始无效答案和字段级校验诊断，单独复测 5 次正常要求人工，最后整组复测 90 次均有效。另通过单元测试修正了既有 ±1% 概率舍入容差端点的浮点误判；不能将先前那次异常直接认定为此原因。
