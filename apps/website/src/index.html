01 / THE MORI WAY

认真把活做好，
也认真替你算账。

从规划到交付，每一步都值得有更合适的选择。

一

把好模型，用在关键处。

用顶级模型规划与审查，把大量执行交给经济的 API 或本地模型。按角色搭配能力，也按角色分配预算。

规划 → 执行 → 审查
二

已有的资源，继续用好。

组合你已有的 GPT 账号、订阅与 API，也支持兼容的第三方服务。从可用的免费额度到付费订阅，按需搭配；额度用完时，也可以切换资源。

账号 / 订阅 / API / 本地模型
三

每一笔花费，心里有数。

按会话、Agent 与模型查看用量、费用和缓存命中情况。了解钱花在哪里，再找到适合自己的组合。

A FEW THINGS TO KNOW

开始之前。

使用 Mori 需要再买一份订阅吗？+
桌面端免费下载，无需购买 Mori 订阅。你可以连接已有账号、订阅、API 或兼容的本地服务；模型访问权限、额度与费用由所选服务决定。
可以只用一个模型吗？+
可以。单模型模式照常可用。需要分工时，再配置主代理和子代理，分别选择模型、工具与 Skills。
本地模型搭配视觉 API，是完全离线的吗？+
调用云端视觉 API 时，需要识别的图片会发送给对应服务。文字执行可以使用本地模型；如果希望视觉也在本地完成，需要接入真实支持图像输入的兼容本地服务。
Mori 现在支持哪些系统？+
支持 macOS 13 及以上（Apple Silicon 和 Intel）、Windows 10/11 x64、Linux x64。产品当前处于 Beta 阶段；安装说明与已知限制可在使用指南中查看。
